# Estudio Jurídico GM & Asociados — sitio web

Sitio estático (HTML/CSS) para abogados y abogadas en San Salvador de Jujuy y El Carmen.
Marca: bordó #841E25, dorado #C7A254, crema #F5F0E7, Poppins.

- `build.py` genera todas las páginas. Con dominio propio: `BASE=https://www.midominio.com.ar python3 build.py`
- Páginas: inicio, 6 áreas de práctica, `/en/` (puerta para el exterior), `sitemap.xml`, `robots.txt`.
- Todo el contacto va al WhatsApp del estudio. No hay celulares personales ni datos privados.
